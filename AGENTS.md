# Agent operating context

Lineum is a public, Apache-2.0 repository. Everything committed here is visible to anyone. Read README.md and docs/decisions/0001-architecture.md before changing code.

## Status

0.1 preview, installable from GitHub, not on PyPI. Do not describe it as released, stable or production-ready, and do not claim user counts, benchmarks or integrations that are not real. Features listed under "What is not built yet" in the README are not built.

## Boundaries

- Keep marketing copy, positioning, internal research and brand source files out of this repository; they live in the private `lineum-landing-page` and `lineum-design` repositories. Final logo files and colours may be copied here.
- Never commit credentials, warehouse connection details, private dbt projects or customer data. Test fixtures and the example project must stay synthetic.
- Do not publish to PyPI, create releases or change repository settings without the maintainer's explicit approval.
- The payload is a contract between `src/lineum/payload.py`, `web/src/types.ts` and `docs/payload.md`; change them together.
- `src/lineum/static/` is generated by `pnpm build` in `web/`; never edit it by hand, and commit it with the source change that produced it.

## Checks

```sh
python -m pip install -e ".[dev,data]"
python -m unittest discover -s tests -t .
ruff check src tests
cd web && pnpm install --frozen-lockfile && pnpm test && pnpm build && git diff --exit-code ../src/lineum/static
```

Pull requests follow `.github/pull_request_template.md`. Sign off commits (`git commit -s`).
